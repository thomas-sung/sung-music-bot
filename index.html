🎵 關於 sung-music-bot

sung-music-bot 是一款免費的 Discord YouTube 音樂機器人， 可以加入 Discord 語音頻道並播放 YouTube 音樂。

使用者可以輸入 YouTube 網址或歌曲關鍵字， Bot 會搜尋 YouTube 並取得對應的音訊串流進行播放。

Bot 使用 Discord Slash Commands， 因此所有主要功能都可以直接透過 / 指令使用。

🎶 支援功能

  • ▶️ 播放 YouTube 音樂
  • 🔎 使用 YouTube 關鍵字搜尋
  • 🔗 使用 YouTube 網址播放
  • ⏭️ 跳過歌曲
  • ⏸️ 暫停播放
  • ▶️ 繼續播放
  • ⏹️ 停止播放
  • 📋 查看播放佇列
  • 🎵 查看目前播放歌曲
  • 🔊 調整音量
  • 👋 離開語音頻道
  • 💤 無歌曲一段時間後自動離開語音頻道

📖 Slash Commands

  • /play — 播放 YouTube 音樂或搜尋歌曲
  • /skip — 跳過目前歌曲
  • /pause — 暫停播放
  • /resume — 繼續播放
  • /stop — 停止播放並清空佇列
  • /queue — 查看播放佇列
  • /nowplaying — 查看目前播放歌曲
  • /volume — 調整音量
  • /leave — 離開語音頻道

使用 Discord 聊天欄位輸入 / 即可查看可用的 Bot 指令。

💤 自動節省資源

為降低免費雲端主機的 CPU、RAM 與網路資源使用量， sung-music-bot 在沒有歌曲播放時會自動管理語音連線。

當播放佇列清空且長時間沒有新的歌曲時， Bot 可以自動離開語音頻道，以減少不必要的資源消耗。

🔒 隱私

sung-music-bot 不以建立使用者個人資料庫為目的， 也不會販售或出租使用者資料。
